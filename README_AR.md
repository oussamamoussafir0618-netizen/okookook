# Kezia Price Scanner — دليل البناء والاستخدام

تطبيق Android أصلي (Kotlin + Jetpack Compose) يعمل بدون إنترنت:
مسح باركود مباشر (CameraX + ML Kit)، قاعدة منتجات محلية (Room)، استيراد XLSX/CSV،
مصمم بطاقات أسعار بالسحب والإفلات، وطباعة ZPL على Zebra ZQ630 عبر Bluetooth أو Wi-Fi.

> **حالة المشروع:** الكود مكتوب بالكامل لكنه **لم يُترجَم ولم يُختبر على جهاز حقيقي** بعد
> (بيئة التطوير التي كُتب فيها لا تملك Android SDK ولا وصولاً إلى مستودعات Google).
> قد يظهر خطأ أو خطآن صغيران عند أول بناء — أرسلهما لي وأصلحهما فوراً.

## 1) بناء APK — الطريقة A: Android Studio
1. ثبّت Android Studio (آخر إصدار) من developer.android.com/studio
2. File ▸ Open ▸ اختر مجلد `KeziaPriceScanner` وانتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. Build ▸ Build Bundle(s) / APK(s) ▸ **Build APK(s)**
4. الملف في: `app/build/outputs/apk/debug/app-debug.apk`
5. انقله إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة")، أو شغّله مباشرة بزر ▶ مع هاتف موصول بـ USB (Developer options ▸ USB debugging).

## 2) بناء APK — الطريقة B: بدون Android Studio (GitHub Actions)
1. أنشئ مستودعاً خاصاً على GitHub وارفع محتوى المجلد كما هو.
2. تبويب **Actions** ▸ Build APK ▸ Run workflow (أو يعمل تلقائياً عند كل push).
3. بعد دقائق نزّل `KeziaPriceScanner-apk` من Artifacts، وفيه `app-debug.apk`.

## 3) تحديث التطبيق مستقبلاً
- عدّل الكود، ثم ارفع `versionCode` (+1) و`versionName` في `app/build.gradle.kts`.
- ابنِ APK جديداً وثبّته **فوق** القديم: البيانات (المنتجات، القوالب، الطابعة) تبقى محفوظة،
  بشرط أن يكون موقَّعاً بنفس المفتاح (استخدم دائماً نفس الجهاز/نفس طريقة البناء).
- إذا غيّرت أعمدة جدول المنتجات في `Data.kt` فارفع `version` في `@Database` وأضف Migration.

## 4) استيراد Excel
الأعمدة: `Barcode | Product Name | Purchase Price | Sale Price | Category`
- قسم **Database** ▸ Import Excel/CSV. ملفات النموذج في مجلد `samples/` (وأيضاً داخل التطبيق: زرّا "Load built-in sample").
- ملف `.xlsx` أو `.csv` فقط (إن كان ملفك `.xls` القديم فاحفظه بصيغة xlsx).
- عند استيراد ملف جديد: الباركود الموجود يُحدَّث، والجديد يُضاف، وأي منتج تغيّر **Sale Price** فيه
  يُعلَّم "تغيّر السعر" ويظهر في تبويب **Price changes** مع السعر القديم مشطوباً.
- بعد طباعة بطاقة المنتج المتغيّر يُعلَّم "مطبوع" فلا يُطبع مرة ثانية (منع التكرار)،
  والقائمة تتيح اختيار ما تريد طباعته قبل التأكيد.
- نصيحة: اجعل عمود الباركود نصّاً حتى لا يحذف Excel الأصفار الأولى (التطبيق يعالج أغلب الحالات تلقائياً).

## 5) الاتصال بطابعة Zebra ZQ630
**Bluetooth**
1. شغّل الطابعة (ضوء Bluetooth يومض).
2. في التطبيق: **Printer ▸ Search nearby printers** واختر الطابعة (اسمها يشبه `XXZQJ…`). 
   إن طلب الهاتف رمز الاقتران فهو غالباً `0000` أو `1234` (أو يظهر طلب تأكيد فقط).
   يمكنك أيضاً اقترانها أولاً من إعدادات Bluetooth في Android فتظهر "paired" في القائمة.
3. **Print test label** للتأكد.

**Wi-Fi** (إن كانت وحدة Wi-Fi مفعّلة في الطابعة): اكتب عنوان IP (من ورقة الإعدادات: اضغط Feed+Power أو من قائمة الطابعة) ثم **Use this Wi-Fi printer**. المنفذ 9100 ثابت.
الهاتف والطابعة على نفس الشبكة.

**ضبط الورق:** من **Label Designer** ضع عرض/ارتفاع الملصق بالملم مطابقاً للورق الفعلي
(مثال 50×30). دقة ZQ630 = 203 dpi (مضبوطة افتراضياً في Settings).
إن انزاح الطباعة، عاير الطابعة (اضغط Feed مطولاً حتى تومض مرتين) أو عدّل الحجم.

## 6) كيف يعمل
- **Scanner:** الكاميرا مفتوحة والتعرّف تلقائي (EAN-13/8، UPC-A/E، Code128، QR). صوت بيب ثم يظهر الاسم والسعر؛
  زر Edit لتعديل المنتج، Print label للطباعة، والمسح يستمر تلقائياً لمنتج آخر. مصباح للإضاءة.
- **Designer:** اسحب العناصر (المتجر، الاسم، السعر، الوحدة، الباركود) بإصبعك، اضبط الحجم/الإظهار/الألوان، احفظ عدة قوالب واجعل أحدها افتراضياً.
  الباركود في المعاينة تقريبي؛ الطابعة تطبع الباركود الحقيقي (EAN-13 أو Code128).
- **الطباعة:** يُولَّد كود ZPL مباشرة ويُرسل للطابعة دون أي تطبيق وسيط.
